# BugKu CTF Writeup - GET
## 题目类型
WEB
## 题目描述
题目出现代码
<br>$what=$_GET["what"];
<br>echo $what;
<br>if($what=='flag')
<br>    echo 'flag{****}';
## 解题过程
<br>1.查看源代码，刷新网页后网络后查看响应头文件内未发现flag
<br>2.了解代码含义，<span style="color:orange">$what=$_GET["what"]</span>，意思是从网址中获取一个叫 what 的参数，并把它存到 $what 变量中。
<br>那么在网址http://XXXXXX/?what=hello中，$what = "hello"。
<br>3.<span style="color:red">echo $what</span>，意思是输出 $what，此时如果我们访问http://XXXXXX/?what=hello，页面会显示hello。
<br>4.if($what=='flag')
<br>    echo 'flag{****}';
<br>意思是：如果 $what 等于 "flag"，就输出真正的 Flag。
<br>5.因此只有当 $what 等于 flag 时，条件才成立。
<br>6.所以我们需要让 $what = flag
<br>7.直接在网址后面加：?what=flag
<br>8.最终访问：http:XXXXXX/?what=flag
<br>9.网页应该会返回真正的flag
## 疑问与解答
### 1.什么是GET请求？
<br>GET 请求是 Web 开发中最常见的一种 向服务器请求数据的方式。
<br>GET 参数通常直接放在 URL 后面
<br>GET请求可以理解为把信息写在网址里，然后发送给服务器。

### <br>2.服务器为什么能识别URL上的代码？
<br>PHP 会读取网址中的代码，GET帮助电脑将数据从前端把数据传递给后端，然后 PHP 等后端程序再读取和处理这些数据。

### <br>3.什么是PHP？
<br>PHP 是一种运行在服务器上的编程语言，主要用于处理网站后台逻辑，例如接收用户数据、判断条件、操作数据库和生成动态网页。
<br>当服务器有 PHP 代码时，PHP 就会把 URL 中的数据读取出来
