# BugKu CTF Writeup - 你必须让他停下
## 题目类型
WEB
## 题目描述
网页中出现不断刷新的页面
## 解题过程
查看源代码发现jpg格式的图片的数字一直在变化，一直快速查看源代码直到10.jpg时发现了flag
## 其他方法
1.查询得知setTimeout('myrefresh()',500);表示每 0.5 秒自动刷新页面，图片会轮流切换。
<br>按 F12 打开开发者工具 → 右上角【设置】（小齿轮图标），找到【Debugger】，勾选 Disable JavaScript（禁用 JS）
<br>禁用 JS 之后，自动刷新的代码直接失效，页面不会再刷新。
<br>手动按 F5 刷新页面，反复刷新直到图片变成 10.jpg，此时按 Ctrl+U 看源代码，flag 就在页面里面。 
## 疑问与解答
### 1.为什么禁用了JS后页面就不会刷新了？
<br>网页自动刷新、局部刷新（AJAX）几乎全靠 JavaScript 实现；禁用 JS，这部分代码直接不运行

### <br>2.js还能干什么？
<br>JavaScript（JS），是运行在浏览器端的脚本语言，网页加载后，在本地浏览器执行代码，可以实现前端交互，
<br>发送网络请求，加密、编码、校验，页面跳转、定时任务，存储数据在浏览器本地。

### <br>3.不断刷新的功能能写在后端吗？
<br>不能，HTTP 协议是无状态、一问一答：默认情况下，浏览器发起请求，服务器响应，连接就断了。服务器不能主动发起请求去控制客户端浏览器。

### <br>4.HTTP协议属于前端还是后端？
<br>HTTP 协议不属于前端或后端的程序，是前端与后端的通信规则，让前端、后端双方都遵守这套规则来对话。
## 笔记
这道题主要学习了：
<br>1.JS中使用setTimeout + location.reload()可实现页面自动刷新
<br>2.JS 是前端代码，禁用 JS 就能终止前端的刷新逻辑
<br>3.页面自动刷新、定时提交请求是浏览器里的 JS 定时器（setInterval / setTimeout）在循环执行，<br>代码跑在客户端浏览器，不是服务器控制。服务器只被动接收请求，不会主动逼页面一直刷新。
<br><span style="color:red">4.只要逻辑写在前端 JS，我们就拥有完全控制权：可以暂停、修改、阻止、篡改。</span>
