# BugKu CTF Writeup - toudengcang
## 题目类型
WEB
## 题目描述
网页显示什么都没有
## 解题过程
1.查看源代码和未发现flag
2.【点击网络】后点击【加载刷新页面】后出现一个document，点击文件打开即可查看flag

## 疑问与解答
### 1.文件为什么在【网络】中？文件所处的位置叫什么？
<br>不是“文件存在网络里”，而是浏览器每次访问网页时，都会通过网络向服务器请求资源。
<br>flag处于服务器 → 浏览器的响应头

### <br>2.为什么只有刷新后才会出现文件？
<br>因为打开网页后，浏览器可能已经把之前的数据加载完了。
<br>当你按 F5 刷新时，会重新发生一次 HTTP 请求：

刷新不是为了让 Flag 出现，而是为了让浏览器重新向服务器发送请求，从而让 Network 抓到服务器返回的数据。

### <br>4.响应头具体是什么
<br>响应头（Response Headers）是服务器在把网页内容交给浏览器时，额外附带的一张“说明书”
<br>服务器返回的东西可以分成两部分
<br>HTTP Response（服务器的响应）
<br>│
<br>├── Response Headers（响应头）← 说明信息
<br>│
<br>└── Response Body（响应正文） ← 真正的网页内容

<br>它们主要是在告诉浏览器：
<br>“我返回给你的这个东西是什么，以及应该怎么处理。”

## 笔记
这道题主要学习了：
<br>1.我们平时打开网页，只能看到浏览器显示出来的页面。
<br>但实际上浏览器和服务器之间还会交换很多信息。
<br>2.刷新网页会重新向服务器发送请求。
<br>3.通过浏览器 F12 的 Network 功能查看浏览器与服务器之间的 HTTP 通信，特别是请求头和响应头。
<br>4.<span style="color:red">网页上看不到的东西，不代表服务器没有返回。</span>
